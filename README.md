# نظام أتمتة موازين الشاحنات والقبانات (Weighbridge Automation System)

نظام متكامل ومتقدم لإدارة وتسجيل أوزان الشاحنات والقبانات الصناعية (**ميزان بسكول ۱۲۰ طن**) مصمم للعمل الميداني على أنظمة **Windows (7/8/10/11)** مع توافق كامل للعمل على بيئات **Linux (Mono / Wine)**.

---

## 🌟 المميزات الرئيسية (Key Features)

1. **واجهة مستخدم عربية بالكامل ومطابقة للموازين الميدانية:**
   - **سند وزن تفاعلي حي (Live Printable Ticket):** يعرض اسم الميزان، الهواتف، رقم التذكرة، بيانات السيارة والعميل، وتفاصيل الوزنة الأولى والثانية وصافي الوزن بالـ كجم.
   - **لوحة تحكم وإدخال سريعة:** مزودة بأزرار تنقل خضراء `[ ◀ ] [ ▶ ]` لتصفح التذاكر السابقة، وإكمال تلقائي لأسماء العملاء والمحافظات ونوع الشحنة.
   - **طابور انتظار السيارات المعلقة (Pending Queue):** فلترة باليوم لتحميل السيارات التي بانتظار الوزنة الثانية بنقرة واحدة.
   - **شاشة رقمية خضراء لقراءة الميزان الحية:** تدعم لمبة بيان استقرار الوزن (أخضر = مستقر، أحمر = متحرك) وصندوق البحث السريع برقم السيارة ومؤشرات منفذ السيريال (`Fire Rx Event Every: 12` و `InputLen: 0`).

2. **قاعدة بيانات SQLite محلية ومؤمنة (Cross-Platform SQLite Engine):**
   - تخزين محلي ذاتي في ملف `weighbridge.db` لا يتطلب أي خوادم أو برامج خارجية.
   - جداول متكاملة للتذاكر (`Weighings`)، كشف حسابات العملاء (`Customers`)، الإعدادات والترويسة (`Settings`)، والمستخدمين (`Users`).
   - حماية كاملة ضد تكرار التذاكر ودعم استعلامات المعاملات الآمنة واسترجاع السجلات.

3. **محرك بروتوكولات الموازين والمحاكي الافتراضي (`ScaleProtocolEngine`):**
   - **Continuous ASCII (Standard):** يدعم مؤشرات Yaohua XK3190 / YHL / A12 ومؤشرات الموازين الإلكترونية الشائعة.
   - **Toledo Continuous:** دعم بروتوكول Mettler Toledo.
   - **CAS CI-Series:** دعم مؤشرات CAS.
   - **Avery Weigh-Tronix / GSE:** دعم موازين Avery.
   - **محاكي ميزان افتراضي (Virtual Scale Simulator):** لتشغيل وتدريب المشغلين وتجربة البرنامج بدون الحاجة لوجود ميزان حقيقي.

4. **صمامات أمان وفلاتر الحالات الحرجة:**
   - كشف القراءات السالبة للميزان (الناتجة عن انزياح الحساسات) وحظر تسجيل التذاكر مع تنبيه تصفير الميزان.
   - التعامل الآمن مع هبوط الوزن المفاجئ للصفر والتحقق الصريح قبل الحفظ.
   - فلتر عازل للضوضاء والبيانات المشوهة والتحقق من الحدود الطبيعية للميزان (-5,000 إلى 200,000 كجم).

## 🚀 التثبيت والتشغيل (Installation & Setup)

### أولاً: التشغيل على أنظمة ويندوز (Windows 7 / 8 / 10 / 11)
حزمة التشغيل المكتبي متوفرة كحزمة مستقلة جاهزة في مجلد `dist/windows-release/` أو عبر فرع `windows-release`:
1. انسخ مجلد `dist/windows-release` إلى جهاز الكمبيوتر في محطة الميزان.
2. انقر نقراً مزدوجاً على **`Weighbridge.exe`** أو **`تشغيل_البرنامج.bat`**.
3. تأكد من بقاء ملف `sqlite3.dll` بجانب البرنامج لعمل قاعدة البيانات.

### ثانياً: التشغيل على أنظمة لينكس (Linux / Mono)
```bash
# تشغيل البرنامج المترجم عبر سكربت التشغيل المباشر:
./run.sh
```

## 🧪 جناح الاختبارات الشامل (Automated Verification Suites)

تم بناء وتنفيذ **جناحي اختبارات مؤتمتة (80 اختباراً)** تؤكد دقة كافة وظائف النظام:

1. **جناح اختبارات النطاق ودورة العمل (`WeighbridgeMasterTestSuite`):**
   - 40 اختباراً تغطي قراءة البروتوكولات، حساب الصافي، طابور الانتظار، العمليات وقواعد البيانات، وصمامات الأمان (40/40 PASSED).
2. **جناح اختبارات حزمة ويندوز وطبقات التوافق (`WindowsBuildCompatibilityTests`):**
   - 40 اختباراً تغطي ترويسة PE32، .NET 4.0 runtime، سلامة الحزمة، تشغيل SQLite الأصلي، والتوافقية الشاملة (40/40 PASSED).

## 🛠️ هيكلية المشروع (Project Architecture)

```text
├── WeighBridge/
│   ├── WeighbridgeForm.cs            # نافذة الميزان الرئيسية والسند التفاعلي
│   ├── WeighbridgeForm.Designer.cs   # تصميم الواجهة الرسومية المتطابق مع الميزان
│   ├── DatabaseService.cs            # محرك قاعدة بيانات SQLite وإدارة التذاكر

│   ├── HistoryForm.cs                # سجل التذاكر وإعادة الطباعة

├── dist/
│   └── windows-release/              # الحزمة المستقلة الجاهزة لويندوز
├── SevenSegment/                     # مكتبة الشاشات الرقمية
└── WeighBridge.sln                   # ملف الحل لمحرري Visual Studio / MSBuild
```
